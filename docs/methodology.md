# Assessment Methodology

## 1. Scope Definition

The assessment was performed in an authorized VMware virtual lab environment.

Target:

192.168.16.129

## 2. Host Identification

Network connectivity and target availability were verified before scanning.

## 3. Port Scanning

Nmap was used to identify exposed TCP services.

Commands included:

- Basic host scan
- TCP port discovery
- Top 100 TCP ports scan

## 4. Evidence Collection

Scan outputs were saved inside the scans directory.

Evidence was preserved for reporting and analysis.

## 5. Security Analysis

Discovered services were reviewed to identify unnecessary exposure and potential security concerns.

## 6. Recommendations

Recommendations focus on:

- Reducing unnecessary services
- Firewall configuration
- Network segmentation
- Service monitoring
- Regular vulnerability assessments
